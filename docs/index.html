À propos de MCEMonitor

MCEMonitor est un logiciel permettant de consulter les mouvements d’un réseau local via les partages Samba, ainsi que les serveurs TV tels que DVBViewer. Il doit être installé sur la machine qui distribue les fichiers, c’est‑à‑dire celle qui possède les partages. Le logiciel fonctionne uniquement sous Windows (minimum Windows 10 64 bits).

Ce que MCEMonitor peut faire

  • Envoyer un rapport journalier des mouvements multimédia : audio, vidéo, images, fichiers TS…
  • Éteindre ou mettre en veille la machine à une heure précise.
  • Envoyer un mail en cas de réveil, d’arrêt ou de plantage.
  • Fournir un serveur Web intégré, consultable de n’importe où, protégé par mot de passe.
  • Conserver une trace des fichiers ouverts sur 7, 14 ou 30 jours, avec une rétention glissante.
  • Générer et télécharger des rapports au format PDF.

Logiciel de gestion réseau par interfaces UI et Web.

On/Off: Gestion des fonctions d'arrêt et de veille.
MediaMonitor: Monitoring des lectures multimédia dans un LAN (SMB), (Infos sur les fichiers multimédia images, films, séries, musiques. FFMPEG, TagLib et lien vers TMDB et Discorg).
MediaMonitor: Monitoring des visionages de canaux TV et des enregistrements de DVBViewer.
SystemMonitor: Monitoring sur les resources materielles CPU, RAM, GPU, Réseaux (Temperatures, charge).
RomMonitor: Monitoring sur les supports physiques tel que HDD, SSD, NVme... (Surcharge, temperatures, Smart).
NetMonitor: Monitoring sur les intrusions Web avec blocage sur Pare-feu (Windivert, GeoIP, Beaconing, Scan de ports).

Reception des monitorings et rapports multimédia par mail.
Extraction des monitorings et rapports en format PDF.

Client Windows permetant d'avoir les notifications des serveurs sur tous les monitorings. (Peut être installé séparément).

Une version du client existe pour Android. Elle permet de recevoir les notifications des monitorings comme le client Windows
(Téléchargement séparé APK).

Espace nécessaire à l'installation: 400 Mo
Système d'exploitations: Windows 10, 11, Server
Ram minimum: 8 Go DDR2 non partagée
